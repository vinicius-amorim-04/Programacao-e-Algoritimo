# 💻 Programação e Algoritmos

## 📚 Sobre

Nesta disciplina, aprendi os fundamentos da **programação e da lógica computacional**, desenvolvendo algoritmos para resolver problemas de forma estruturada e eficiente.

Durante os estudos, trabalhei com variáveis, operadores, estruturas condicionais e estruturas de repetição, além da criação de algoritmos e fluxogramas.

---

## 🧠 O que aprendi

| Área                | Conhecimentos                              |
| ------------------- | ------------------------------------------ |
| 🧩 **Lógica**       | Raciocínio lógico e resolução de problemas |
| 📋 **Algoritmos**   | Criação e organização de algoritmos        |
| 🔀 **Condicionais** | Estruturas `if` / `else`                   |
| 🔄 **Repetição**    | Estruturas `for` e `while`                 |
| 📦 **Variáveis**    | Armazenamento e manipulação de dados       |
| ➕ **Operadores**    | Operadores matemáticos e lógicos           |
| 📊 **Fluxogramas**  | Representação visual de algoritmos         |
