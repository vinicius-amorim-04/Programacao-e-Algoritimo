
# Programação e Algoritmos

## Sobre

Nesta disciplina aprendi os conceitos básicos de programação e lógica computacional. Estudei como criar algoritmos para resolver problemas, utilizando estruturas de decisão, repetição e variáveis para desenvolver soluções de forma organizada e eficiente.

## O que aprendi

- Conceitos de lógica de programação;
- Criação de algoritmos e fluxogramas;
- Uso de variáveis e operadores;
- Estruturas condicionais (if/else);
- Estruturas de repetição (for e while);
- Desenvolvimento de programas para resolução de problemas.

## Conclusão

A disciplina foi importante para desenvolver o raciocínio lógico e entender os fundamentos da programação, servindo como base para o aprendizado de linguagens de programação e o desenvolvimento de sistemas.
